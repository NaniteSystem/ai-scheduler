🗂️ Scheduler — карта проекта

Живая доска проекта: добавляй функции, описания и референсы прямо здесь. Claude читает project-map.json и работает по нему — вся работа отражается тут.

Как это работает (синхронизация с Claude):
  1. Редактируй прямо на странице — всё сохраняется в браузере автоматически.
  2. Нажми «📤 Экспорт для Claude» → сохрани файл project-map.json в папку проекта (рядом с этой страницей).
  3. Скажи Claude: «обнови по карте» — он прочитает project-map.json, сделает работу и запишет туда новые статусы/заметки.
  4. Нажми «📥 Импорт» и выбери обновлённый project-map.json, чтобы увидеть правки Claude.
