# Редизайн UI (2026-06-24) — спецификация

Полный реског приложения под референсы (светлые макеты task-менеджера, индиго-акцент). Делается волнами по экранам через систему тем (CSS-переменные).

## Тема
- **Светлая по умолчанию + тёмная опцией** (переключатель в Profile/Настройках).
- Реализация: CSS-переменные в `index.css` (`:root` = светлая, `.theme-dark` = тёмная), класс темы на корне App, `theme` в store (persist).
- Палитра (светлая): bg `#eef1f8`, surface `#ffffff`, surface-2 `#f4f6fb`, border `#e9ecf3`, text `#1b1e2b`, dim `#6c7280`, primary `#4f5bd5`→`#7b84ea` (градиент), on-primary `#fff`, мягкие тени.
- Тёмная: bg `#050505`, surface `#0d0d0d`, border `#1f1f25`, text `#ececf0`, primary indigo `#6366f1`.

## Стиль карточек (из рефов)
- Белые скруглённые карточки (rounded-2xl), мягкая тень, **цветная полоска слева** (4px) у задач/сессий.
- Заголовок секции + синяя pill-кнопка справа («View Task»-стиль).
- Шапка-приветствие: синий градиентный блок «Hi, {name}!» + дата + колокольчик + аватар; внутри прогресс-бар дня + кнопка.

## Нижняя навигация — 5 пунктов, минимализм
**Home · Calendar · ➕(центр) · Stats · Profile**
- **Home** — дашборд как на фото: приветствие, дневной прогресс, «Today's Task» (горизонтальные карточки), «Upcoming Task». Впитывает сегодняшние задачи/привычки/сессии.
- **Calendar** — Schedule, вид «День»: полоска дней (S M T W…) сверху + таймлайн на всю ширину, белые карточки событий с цветной полоской, ⋮-меню, индикатор текущего времени синей pill.
- **➕ (центральная круглая)** — существующая кнопка создания (задача/привычка/сессия/цель) — открывает выбор.
- **Stats** — собирательный хаб (как фото Discover/Tracked Habits): настроить **Goals, Habits, повторяющиеся задачи, шаблоны задач** + категории/темы + **статистика выполнения задач** (графики). Сюда же аналитика привычек/целей.
- **Profile** — профиль пользователя, аккаунт (Google-вход позже), Настройки (язык, расписание, уведомления, **тема**), Архив.
- **Home** — впитывает **Inbox (GTD) в упрощённом виде**.

## Куда уезжают прежние модули (IA)
- Goals — список доступен из Home и из Profile.
- GTD-задачи — в Home (сегодня) / создание через ➕.
- Habits — сегодня в Home; полный экран + аналитика в Stats; управление в Profile.
- AI День-архитектор — через ➕ или в Profile.
(Старая боковая навигация на десктопе может остаться расширенной; нижняя — 5 пунктов.)

## Точечные правки
- Убрать из Настроек блок «Appearance / Interface density» и «Data / Reset all data».
- (density как фича убирается из UI; сброс данных убрать с экрана.)
- Schedule по умолчанию = День.
