# JLPT N5 — колода Anki

- `JLPT_N5_vocab.apkg` — готовая колода, импорт: Anki → Файл → Импорт.
- `n5_vocab.tsv` — исходный словарь (кандзи / кана / перевод / категория), правится руками.
- `build_deck.py` — пересборка: `pip install genanki && python3 build_deck.py`.

Типы карточек: иероглифы → чтение+перевод (только для слов с кандзи), кана → перевод, русский → японский.
Теги: `N5`, категория, `с_кандзи` / `только_кана`.
