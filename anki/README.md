# JLPT N5–N2: колоды Anki (単語)

| Уровень | Файл | Слов |
|---|---|---|
| N5 | `n5/JLPT_N5_vocab.apkg` | 715 |
| N4 | `n4/JLPT_N4_vocab.apkg` | 584 |
| N3 | `n3/JLPT_N3_vocab.apkg` | 938 |
| N2 | `n2/JLPT_N2_vocab.apkg` | 874 |
| Все сразу | `JLPT_all_vocab.apkg` | 3111 |

Импорт: Anki → Файл → Импорт. Колоды попадают в `JLPT::N5 単語`, `JLPT::N4 単語` и т.д.

Слова N4–N2 разложены по разделам в духе 新完全マスター 語彙: 名詞, 名詞・する, 動詞, 複合動詞,
い形容詞, な形容詞, 副詞, オノマトペ, 外来語, 接辞 (приставки и суффиксы), 慣用句. Это не копия книги,
а собственный список. Слово, которое уже есть на более низком уровне, в старшую колоду не попадает.

Типы карточек: иероглифы → чтение+перевод (только для слов с кандзи), кана → перевод, русский → японский.
Теги: уровень (`N3`…), раздел, `с_кандзи` / `только_кана`.

Правка: меняешь `nX/nX_vocab.tsv` (кандзи / кана / перевод / раздел), потом
`pip install genanki && python3 build_decks.py`.
