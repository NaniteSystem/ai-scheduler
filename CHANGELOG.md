# Nebulla changelog

This project uses Semantic Versioning (`MAJOR.MINOR.PATCH`). A version is raised only after explicit user approval or a direct request to issue a new version.

## 1.4.0 — 2026-07-15

- Reworked primary navigation around Manage and Profile.
- Improved task capture, GTD flow, upcoming tasks and bulk rescheduling.
- Added flexible Pomodoro links, Android home-screen widgets and native voice-recognition fixes.
- Refreshed the visual system and mobile navigation.

## Version policy

- **MAJOR**: a breaking product or data-model change.
- **MINOR**: a user-visible, meaningful feature release.
- **PATCH**: fixes and small, non-breaking refinements.
